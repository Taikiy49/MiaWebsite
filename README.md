## Overview

A personal portfolio for Mia Umeda, presenting human resources experience, education, skills, and recognition with original photographs and organization logos.

## What’s inside

- Portfolio content composed in a React entry point.
- Original personal and event photographs in the public media directory.
- Vite development/build workflow and Vercel configuration.

## Getting started

Use Node.js 22, as specified in `package.json`:

```sh
npm ci
npm run dev
```

Create a production build with `npm run build`; inspect it with `npm run preview`.
